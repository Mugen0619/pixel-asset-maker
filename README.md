# PIXEL-ASSET-MAKER(ドット絵・ゲーム素材自動生成アプリ)

2Dゲームを作る個人開発者向けの、ドット絵・ゲーム素材づくりを助けるツールです。AIによる素材の生成と、手動での編集を組み合わせます。

> **現在の状況:** 構想・初期セットアップ段階です。アプリ本体はまだ実装していません。技術構成や機能は「候補」の段階で、確定していません。

## プロジェクトの概要

AIで素材のたたき台を作り、それを手作業で仕上げて、ゲームエンジンに取り込みやすい形式で書き出す。この一連の作業を1つのツールで行えるようにすることを目指しています。

## 解決したい課題

- 2Dゲームの素材(ドット絵など)を自分で用意するのに時間がかかる。
- 用意した素材を、ゲームエンジンで使える形式・サイズに整える手間がかかる。

## 対象ユーザー

Godot・Unityなどで2Dゲームを制作する個人開発者。

## 想定する主な機能

機能の詳細は、今後の要件定義で確定します。現時点の想定は次のとおりです。

| 機能 | 内容 |
|---|---|
| AIによる素材生成 | AIで素材のたたき台を生成する |
| 手動編集 | 生成した素材や、一から描く素材を、ドット単位で編集する |
| 書き出し | ゲームエンジンに取り込みやすい形式で出力する |

初期のMVP(最初に完成させる最小限の範囲)では、ユーザー登録・データベース・クラウド保存は導入しない方針です。

## 今後の開発手順

1. **要件定義:** MVPの機能一覧を確定する。
2. **技術構成の確定:** 候補を検証し、決定内容を[decisions.md](./decisions.md)に記録する。
3. **開発環境の構築:** 依存パッケージを導入し、バージョンを記載する。
4. **手動編集(ドット絵エディタ)の実装:** AIのAPIがなくても開発・確認できる部分から始める。

順番は、要件定義の結果によって見直します。

## 開発の進め方

- 学習を兼ねた個人開発です。AI(Claude Code・ChatGPT・Gemini)を活用しつつ、指示・レビュー・検証と最終判断は開発者本人が行います。
- AIが生成したコードの処理内容と、技術を選んだ理由を、開発者自身が説明できる状態を目指しています。
- 作業は、Issue → ブランチ → Pull Request の流れで進めます。
